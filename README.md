# MarketCraft — Small Business E-Commerce Platform

An all-in-one e-commerce management suite and high-converting storefront builder tailored specifically for independent makers, artisanal studios, and small retail businesses.

---

## 🌟 Overview & Key Features

MarketCraft bridges the gap between boutique customer shopping and small-business merchant operations:

### 🛍️ 1. Customer-Facing Digital Storefront
- **Artisanal Campaign Hero**: Studio showcase with clean editorial typography and unboxed announcement bar.
- **Curated Catalog Grid**: Filter by product categories (Ceramics, Textiles, Apothecary, Stationery), live instant search, in-stock filter, and sorting.
- **Contiguous Purchase Module (PDP)**: Option/variant selection, live stock tracker with low-stock warnings, quantity stepper, studio origin and care details, and verified reviews list with review submission form.
- **Slide-Over Cart Drawer**: Free shipping threshold meter, quantity adjustments, and promotional discount code validation (`WELCOME10`, `FREESHIP`, `AUTUMN20`).
- **Complete Checkout Flow**: Multi-step checkout with customer address collection, courier selection, simulated payments (Credit Card, Apple Pay, Cash on Delivery), and printable confirmation receipts.

### 📊 2. Merchant Operations Hub
- **Executive Dashboard**: Real-time gross sales, order volume, average order value (AOV), inventory retail valuation, and gross margin calculations.
- **Products & Inventory**: Manage retail vs. wholesale costs, unit margins, SKU codes, inline inventory adjustments, product duplication, and full Add/Edit modal.
- **Orders & Fulfillment**: Status filter tabs (`Processing`, `Shipped`, `Delivered`, `Cancelled`), carrier selector (USPS, UPS, FedEx, DHL, Courier), simulated tracking numbers, and printable packing slips.
- **Customer CRM**: Client directory tracking lifetime spend, total orders, segments (`VIP`, `Repeat`, `New`, `Wholesale`), and client notes.
- **Discounts & Coupons**: Custom percentage or flat rate promotional codes with minimum spend rules and redemption tracking.
- **Storefront Customizer**: Live editor for boutique name, brand tagline, hero headlines, shipping policies, and tax rates.
- **Data Portability**: Full JSON export and restore for offline backups.

### ⚡ 3. Market & Counter POS Register
- Tailored for pop-up markets, craft fairs, and in-person boutique checkout.
- Rapid product quick-tiles, instant SKU search, fast cash bills calculator (`$20`, `$50`, `$100`, `Exact`), change-due calculation, and printable thermal receipts.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion
- **State & Storage**: React Context with LocalStorage persistence and JSON export/import

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm, pnpm, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/Eniola985/marketcraft-ecommerce-or-small-business-ecommerce.git
cd marketcraft-ecommerce-or-small-business-ecommerce

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open `http://localhost:3000` or `http://localhost:5173` in your browser.
